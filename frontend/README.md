# 前端README

## 项目概述
这是一个基于 React 构建的前端应用程序，集成了摄像头功能、语音识别功能以及精美的动画效果。用户可以打开摄像头进行视频展示，通过语音输入消息，系统会显示用户的语音消息并给出 AI 回复。同时，界面上有炫酷的粒子背景和动态的气泡动画，增强了用户体验。项目使用 Tailwind CSS 进行样式设计，借助 Rsbuild 进行项目构建。

## 功能特性
1. **摄像头控制**：用户可以通过点击按钮打开或关闭摄像头，视频会在界面上实时显示。
2. **语音识别**：用户点击麦克风按钮开始语音输入，系统会识别用户的语音内容并显示在界面上，同时给出简单的 AI 回复。
3. **动画效果**：
    - 背景有动态的粒子效果，增强视觉体验。
    - AI 气泡动画会根据语音输入的状态和音频强度进行动态变化。
    - 思想气泡动画有多个凸起的波浪，呈现出动态的效果。
4. **样式设计**：利用 Tailwind CSS 提供的实用类快速构建美观且响应式的界面。

## 技术栈
- **React**：用于构建用户界面和管理组件状态。
- **react - tsparticles**：用于实现背景的粒子动画效果。
- **framer - motion**：用于创建各种动态动画效果，如气泡的缩放、旋转等。
- **Web API**：使用 `navigator.mediaDevices` 访问摄像头和麦克风，`SpeechRecognition` 进行语音识别。
- **Tailwind CSS**：用于快速搭建界面样式。
- **Rsbuild**：作为项目的构建工具，提供高效的构建能力。

## 安装与运行
### 安装依赖
确保你已经安装了 Node.js 和 pnpm。在项目根目录下运行以下命令安装项目依赖：
```bash
pnpm install
```

### 启动开发服务器
安装和配置完成后，运行以下命令启动开发服务器：
```bash
pnpm dev
```
打开浏览器，访问 `http://localhost:3000` 即可看到应用程序的界面。


## 使用说明
1. **摄像头控制**：在界面上找到视频区域，点击“打开摄像头”按钮即可开启摄像头，再次点击可关闭。
2. **语音输入**：点击右下角的麦克风按钮开始语音输入，系统会实时识别你的语音内容。再次点击按钮停止语音输入。
3. **查看消息**：语音输入的内容会显示在界面下方的消息区域，同时会显示 AI 的简单回复。

## 注意事项
- 由于使用了 `navigator.mediaDevices` 访问摄像头和麦克风，需要在安全的环境下运行（如 `https` 协议），否则可能会出现权限问题。
- 语音识别功能依赖于浏览器的 `SpeechRecognition` API，不同浏览器的支持情况可能有所不同。建议使用 Chrome 浏览器以获得最佳体验。
